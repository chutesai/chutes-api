# Security traceability — Loki read routes

## Scope

This branch adds `GET /logs/instances/{instance_id}` (`read_instance_logs`) and `GET /logs/miner` (`read_miner_logs`) on the existing `/logs` router. Policy is in `authorize_user_read`, `authorize_miner_read`, `require_instance`, `require_launch_config`, `decode_launch_jwt`, and `lines_before_activation` (`api/chute_logs/read_access.py`).

Not modified: log ingest, `stream_logs`, `stream_miner_logs`, `GET/PUT/DELETE /logs/debug/{chute_id}`, either CLI, and sek8s. `uv run pytest tests/unit/test_chute_logs.py -q` still passes (17 tests). The new tests are only in `tdd/tests/test_chute_log_reads.py`.

"Red" below means that test's assertion fails. **Gap** means commenting out the control leaves every test in that file green.

## What these tests do not cover

- Loki network isolation. Marked UNCLEAR. Comment only. Deployment.
- `CVM_PROXY_SECRET` / `X-Cvm-Proxy-Auth`. Ingest only. Not exercised by `tdd/tests/`.
- Loki retention versus the encrypted-log 4-hour Redis TTL. Marked UNCLEAR. No code and no test.
- Unparseable `ts` on the miner path. Marked UNCLEAR. The code drops those lines when a cutoff is set. No test.
- `failed_at` with no `activated_at` and no instance. Marked UNCLEAR. No behavior and no test. See below.
- `purpose="logs"` and `require_exp=True`. Both are in the production functions. This file never calls them for real.
- A sharee of a public chute.
- The `"Instance activated:"` sentinel is not what the filter searches for. No test would catch a switch to that string.
- `chutes_support` on the existing debug routes.
- Any ingest, proxy, or mTLS regression.

## Deferred

- `lines_before_activation` drops lines in process memory after Loki has already returned them. The cutoff should move into the LogQL query (`ts` compared to `activated_at`). The tests lock the drop, not where it runs.
- `failed_at` set, `activated_at` null, and no instance returns the stored lines with no time cutoff. The live miner stream returns 422. That needs a product decision before any gate is added.
- CLI cutover is another branch. `chutes` and `chutes-miner` still call the old streams.
